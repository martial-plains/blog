* アイスランド語を学び始めた理由

昨年のはじめ、私はアイスランド語を学び始めました。長年スウェーデン語を学んできて、そのルーツについてもっと知りたくなったのです。しかも、アイスランド語は現存する言語の中で古ノルド語にいちばん近いと、前々から聞いていました。

本当に、それだけでした。壮大な計画があったわけではなく、すでに知っている言語がどこから来たのかという好奇心だけでした。

* まずノートがあった

私は Obsidian と Apple Notes を使い始めた頃からずっとノートを取ってきました。ただ、しばらくすると、スマートフォンでノートをほとんど触っていないことに気づきました。考えてみると、あちらでは編集するより /読む/ ほうがずっと好きなのです。しかも、ノートのほとんどは、そもそもノートパソコンで作られていました。

そこで、ノート作成はすべてノートパソコンに移し、Obsidian を使うことにしました。特に Bases が登場してからは快適でした。ところが、そこで書いているあいだ、Meow のキーバインドが恋しくてたまりませんでした。

はい、わかっています。Vim のキーバインドを使う人のほうがずっと多いですよね。でも、Meow のほうがなぜかずっと手になじみますし、それを使える場所は Emacs だけなのです。結局、それが私を Emacs に引き戻しました。

なぜ Markdown ではなく Org なのか。いちばんの理由は、ノートを持ち運びやすいからです。Markdown は多くの場所で使えますが、 /方言/ があまりにも多いのです。私の知る限り、Org mode の方言は一つだけで、その上に拡張が積み重なっています。Org は Markdown に書き出せますが、その逆はできません。Org は必要なことをすべてこなしてくれるので、そのまま使い続けています。

どういうわけか、これもまた Emacs のプロジェクトになってしまいました。😂

* ノートを本にしようと決めた理由

アイスランド語を学び始めて1年4か月が経った頃、たまったノートの量を眺めながら、こう思いました。 /アイスランド語はとても美しく、歴史のある言語です。もっと多くの人が実際に学んでくれたらいいのに。/

そのとき、ひらめきました。アイスランド語の語彙についての本を書けば、この言語がどれほど美しく見えるかだけでなく、その背景にある文化がどれほど素晴らしいかも、人々に伝えられるかもしれない、と。

それは、どんな本にするかも決めました。アイスランド語に取り組み始めたとき、私はスウェーデン語のときと同じような助けがあるものと思っていました。教科書、辞書、段階別読本などです。実際に見つかったのは、優れた教材が点在している状況で、語彙と文法と文化を一か所にまとめたものはほとんどありませんでした。だからこれは、学び始めたときに自分が持っていたかった本です。

私はアイスランド語の言語学者ではありませんし、この本はきちんとした文法書や辞書の代わりにはなりません。これは、 *学習者が、ほかの学習者のために書いた本* です。 /私/ が理解し、覚えるのに役立ったことを書きました。

* スウェーデン語とのつながり

私は「ラダリング法」で言語を学んでいます。すでに知っている言語を踏み台にして、次の言語へ進む方法です。スウェーデン語は /とても/ 役に立ちました。ゲルマン語の基本語彙の多くは、明らかに同系統の語です。 /Ég er heima/ に出会ったとき、 /heima/ がスウェーデン語の /hemma/ と同じ系統の語だとすぐにわかりました。 /vatn/, /hús/, /bók/, /dagur/ なども同じです。

単語だけではありません。アイスランド語の /föðurbróðir/ と /móðurbróðir/ は、スウェーデン語の /farbror/ と /morbror/ とまったく同じ作りで、 /föðursystir/ と /móðursystir/ も /faster/ と /moster/ と同じです。ただ、スウェーデン語は日常会話では祖父母にも同じ方式を使います (/farmor/, /mormor/)が、アイスランド人はたいてい /amma/ と /afi/ と言うだけです。

そして、落とし穴があります。スウェーデン語のせいで、アイスランド語の形態論を甘く見てしまうことがあるのです。スウェーデン語は、古いゲルマン語の格変化の体系をほとんど失いました。アイスランド語は失っていません。

#+begin_example
Ég sé manninn.
#+end_example

#+begin_example
Ég tala við manninn.
#+end_example

さらに、名詞は格、数、性、定性などによって変化します。同じ「男」が、ある文では /maðurinn/ に、別の文では /manninn/ になります。正直なところ、私はもっとスウェーデン語に近いものを予想していました。つまり、どちらの文でも「男」が同じ形になる、次のようなものです。

#+begin_example
Jag ser mannen.
Jag pratar med mannen.
#+end_example

最初のうち、スウェーデン語は語彙をただで与えてくれる一方で、その語彙が文法的にどう振る舞うかについては、間違った期待も与えてしまいます。この緊張関係が十分に面白かったので、本の中に居場所を与えることにしました。それが「Swedish Connection」ボックスで、スウェーデン語がどこで助けになり、どこでそっと足をすくうのかを示しています。

* 書いていて驚いたこと

大きな驚きは、Org のスタイル設定がどれほど簡単かということでした。PDF には LaTeX、Web 版と ePub 版には CSS を使います。道具と格闘することになると思っていたのに、実際にはずっと少なくて済みました。

出版を決めた当初は、Apple Pages で書き始めました。無料で、ひとつの要素のスタイルを変えるとすべてに反映されるからです。そこから Emacs と Org mode に切り替えたきっかけは、もっとささやかなものでした。私は夜に本の作業をすることが多く、macOS の Night Shift をオンにしていても、白い背景が目にこたえたのです。

自分でコントロールできるエディタで書くのは、本当に気持ちのいいことです。そして Org mode で書いていると、制作の全工程を自分でコントロールしているような気持ちになります。

* 実際にどう作ったか

ここからは技術的な話です。本全体は Git リポジトリに入っていて、章ごとに Org ファイルが一つあり、それらを =#+include= 行でまとめる =book.org= が一つあります。

#+begin_src org
,* Getting Started

,#+include: "chapters/pronunciation.org" :minlevel 2
,#+include: "chapters/grammar-at-a-glance.org" :minlevel 2
,#+include: "chapters/greetings-and-everyday-phrases.org" :minlevel 2
#+end_src

=:minlevel 2= を指定すると、各章のトップレベルの見出しが、その =\part= の下の LaTeX の =\chapter= になります。章は全部で22あり、6つの部に分かれています。ヒント、警告、文法メモ、文化メモ、Swedish Connection ボックスは、すべて Org の特殊ブロック (=#+begin_swedish= など) にすぎず、プリアンブルと CSS でスタイルを付けています。

全体の流れはこうなっています。

#+begin_example
                 ┌──→ LaTeX (XeLaTeX) ──→ PDF ──→ KDP
Org files ───────┤
                 └──→ HTML ──→ Pandoc ──→ EPUB
#+end_example

コマンドひとつで、すべてをビルドします。

#+begin_src sh
emacs --batch -l publish.el -f book-publish-all
#+end_src

各章末の練習問題、解答集、用語集を、各章の語彙表からそのまま生成する小さな Python スクリプトも書きました。これで、新しい単語を用語集に入れ忘れることがありません。どういうわけか、これもまた /もうひとつの/ Emacs プロジェクトになり、さらには Python のプロジェクトにもなりました。

** IPA をめぐる騒動

本当に苦労したのは、 *IPA* を動かすことだけでした。ここでは少し大変なことになりました。最終的なコツは、IPA を文字列として扱うのをやめ、独立したものとして扱うことでした。独自の Org リンクタイプを定義し、 =[[ipa:ˈθraʊstʏr]]= とどこにでも書けば、各形式に正しく書き出されるようにしました。

#+begin_src emacs-lisp
(org-link-set-parameters
 "ipa"
 :export (lambda (path desc backend)
           (cond
            ((org-export-derived-backend-p backend 'latex) (format "\\ipa{%s}" path))
            ((org-export-derived-backend-p backend 'html) (format "<span class=\"ipa\">%s</span>" path))
            (t path))))
#+end_src

LaTeX 側では、 =\ipa= が Doulos SIL に切り替えるだけで、必要な記号がそろっています。

#+begin_src latex
\newfontfamily\ipaFont{DoulosSIL-Regular}[Path=\doulosdir, Extension=.ttf]
\DeclareRobustCommand{\ipa}[1]{{\ipaFont #1}}
#+end_src

もうひとつ厄介だったのが、本文フォントの Noto Serif に、「X → Y」のような形で使う → の矢印がないことです。代替フォントを追加しないと、PDF から黙って消えてしまいます。こういう些細なことは、校正刷りをにらんでいるときにしか見つかりません。それでも、なんとかすべての記号を表示させることができました。

本を書いているあいだは、作家になった気分でした。「出版」ボタンを押したとき、本当に本を作ったのだと実感しました。

* /Icelandic Vocabulary/ の中身

/Icelandic Vocabulary: A Learner's Companion to the Words, Grammar and Culture of Iceland/ は、英語を話す人で、役に立つアイスランド語の語彙を身につけたい人のための本です。完全な初心者でも、学習に戻ってきた人でも、アイスランド旅行を計画している人でも使えます。スウェーデン語を知っている必要はありませんが、知っている人には、Swedish Connection ボックスがそれを活かす方法を示します。

6つの部で構成されています。

- *Getting Started*: 発音、必要な文法の簡単な概観、あいさつと日常のフレーズ
- *People and Everyday Life*: 家族、仕事、学校、体と健康
- *Home and Daily Living*: 家、衣服、飲食、時間、数、色
- *Nature and the Outdoors*: 動物、農業、風景、アイスランドの歴史
- *Recreation, Culture and Entertainment*: 趣味、スポーツ、祝日、芸術、メディア
- *Travel and the Wider World*: 交通、旅行、国と国籍

各章は導入から始まり、テーマ別の表で語彙を示し、例文と短い会話で実際の使い方を見せ、練習問題で終わります。巻末には、動詞表、格変化表、前置詞と格のガイド、平易な英語による文法用語の一覧、解答集、アイスランド語–英語の用語集があります。
